# X Wallet 1.5.1+14 — live USD values and a clearer trust card

Source version: `1.5.1+14`. Tested commit: `ec5b77fafa79d0f2e87f7688ac90aebfbfdf61ab`; squash merge: `107ab22b4f89b13c1429476a2f15c2b4af2aadca`.

This patch makes live USD values more reliable by using multiple public market
sources, and replaces the old safety notice with a positive "Built for safety"
card. No wallet key, address, balance, or user identifier is sent to a price
service.

## Highlights

- **Live USD values** under BNB, USDT, USDC and supported tokens.
- **CoinMarketCap first**, with automatic fallback to CoinGecko, Binance, and
  Coinbase. If one source is blocked or rate-limited, the next one answers.
- **Honest source label** in the assets header: `USD · CoinMarketCap`,
  `USD · CoinGecko`, or `USD · Binance`.
- **Stablecoin continuity**: USDT/USDC/BUSD fall back to $1 only when every
  market source fails, so the row never loses its approximate USD value.
- **Built for safety card**: non-custodial, encrypted vault, local signing,
  every transfer approved by you, no account, no cloud, no analytics.
- **No AI or builder access**: no endpoint, SDK, account, remote config, or
  builder-controlled server can read or control a wallet.
- Existing Android hardening from 1.5.0 is unchanged: native Argon2id,
  background/idle vault lock, 6-digit PIN rules, wipe-after-failures,
  FLAG_SECURE, overlay-touch rejection, R8/obfuscation.

## No AI or builder access

X Wallet contains no AI endpoint, analytics SDK, ads SDK, remote config, push
service, or builder-controlled server. DeepSeek, the AI assistant, and the
builder cannot read, copy, receive, or control a user's vault, keys, balances,
addresses, or activity at runtime.

Price sources receive only fixed public coin symbols or IDs. The IP echo is
used only when the user runs a route test. See
[`docs/NO_RUNTIME_ACCESS.md`](https://github.com/jackh0006/X-Wallet/blob/main/docs/NO_RUNTIME_ACCESS.md).
