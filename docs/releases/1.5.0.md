# X Wallet 1.5.0+13 — Android KDF, lock hardening, and a clearer wallet

Source version: `1.5.0+13`.

This release fixes the highest-risk Android findings from
`docs/ANDROID_AUDIT.md` and replaces the desktop-shaped first impression with a
calmer, modern wallet surface. The vault format, signing rules, spending
controls, and network policy are unchanged.

## What changed

### Android security

- Android now ships the **reference native Argon2id** library
  (`libargon2-arm.so`) and loads it through the existing FFI path. The 64 MiB /
  t=3 / p=4 parameters are unchanged.
- The vault is locked when the app leaves the foreground and after the idle
  timeout **even when no PIN is configured**. The PIN gates the unlock screen;
  it is not the lock itself.
- New PINs must be 6–12 digits and cannot be repeated, sequential, or a common
  trivial PIN. Existing PIN records keep verifying.
- Optional "erase after 10 wrong PINs" (on by default, user-configurable) with
  crypto-erasure and a clear warning.
- Biometric unlock now asks for **strong biometrics only** and persists across a
  brief background transition.
- `flutter_secure_storage` no longer resets on error; a Keystore read failure
  fails closed instead of silently deleting the only device factor.
- `FLAG_SECURE` remains on every screen, and the Android view now rejects
  obscured/overlay touches (`filterTouchesWhenObscured`).
- Network security config trusts system CAs only and explicitly lists the
  public price and IP-echo hosts.
- Release builds use R8 minification, resource shrinking, and Dart obfuscation.
- Adaptive/themed Android icon and Android 12+ splash derived from the existing
  logo.

### UI

- New blue Material 3 palette, softer cards, larger primary buttons, and a
  cleaner app bar.
- Home now leads with a total-balance hero card, Send/Receive, and asset rows
  with optional USD values.
- New **Activity** tab with All/Pending/Done/Failed filters and receipt detail.
  The public address inspector moved to Settings → Security → Inspect any
  address, so no feature was removed.
- Android and Linux wallet screens use the same asset cards and USD rows.
- "Show USD values" is a setting. When on, the app requests only fixed public
  coin IDs from CoinGecko; no address, balance, vault, or identifier is sent.
- Explorer and trusted-source links open in the Android system browser instead
  of being copied.
- Desktop-only storage controls (open data folder, move vault, reset path) are
  hidden on Android.
- Secret fields disable IME personalized learning.

### Kept on purpose

- English-only UI (the earlier product decision). The code is structured for
  future ARB translations, but no machine-translated language is shipped.
- Linux build and desktop features.
- Cold/offline signing, address-poisoning checks, spending limits, allowlist,
  freeze signing, exact review, and hold-to-confirm.
- No analytics, ads, tracking, accounts, remote config, or AI endpoint.

## No AI or builder access to user data

X Wallet contains no AI endpoint, analytics SDK, ads SDK, remote config, push
service, or builder-controlled server. DeepSeek, the AI assistant, and the
builder cannot read, copy, receive, or control a user's vault, keys, balances,
addresses, or activity at runtime.

The only outbound hosts are the selected BSC RPC node, optional BscScan, the
public CoinGecko price endpoint (fixed coin IDs only, when USD display is on),
the public ipify IP echo (only when the user runs a route test), GitHub for
public links, and Orbot on Android. See `docs/NO_RUNTIME_ACCESS.md` for the
host list and verification commands.

## Honest limits

- No physical Android device run was performed in this environment. The
  Huawei Y9 2019 runtime, StrongBox/TEE selection, biometric prompt, TalkBack,
  camera, and Orbot fail-closed behavior remain **NOT TESTED**.
- No independent audit.
- No hardware-wallet support.
- No QR camera scanner or token-approval screen in this release.
- Dart managed memory cannot guarantee secure erasure; the documented limits
  still apply.
- Large-value custody is not certified.
