This release focuses on recovery, multiple independent vaults, and the
security fixes found in the 1.5.3 hardening review. It is **not** an
independent audit and does not certify large-value custody.

## Highlights

- **Portable backups.** Exported backups now use a new `BNBBKP01` envelope
  protected by Argon2id (64 MiB, t=3, p=4) and XChaCha20-Poly1305. A backup
  depends on its password only, so it restores on a new device without the
  old machine's device secret. Vault files stay device-bound.
- **Multiple vaults.** Up to three independent vaults, each with its own file
  and password, can be created, renamed, switched, password-changed and
  deleted from Settings → Vaults. Pending transactions are scoped to the
  active vault. The pre-1.5.3 single vault is adopted as "Main" without moving
  the file.
- **Change vault password in the UI.** The existing re-key operation is now
  exposed with confirmation and re-read verification.
- **Broadcast safety.** The exact signed bytes and hash are persisted before
  the first network attempt. An uncertain broadcast is marked "Unconfirmed",
  blocks new sends for that vault until it is checked, and can no longer be
  retried with a fresh nonce (which could pay twice).
- **Cancel works.** The cancel path now signs an explicit zero value and
  passes the same review verification as a send.
- **Approval review.** ERC-20 `approve` now decodes and displays the spender,
  warns on any approval, flags allowances at or above 2^255, and decodes
  `increaseAllowance`/`transferFrom`. The standard ABI address-word decoding
  bug that rejected every normal transfer is fixed.
- **Token identity.** A non-canonical contract that uses a known symbol is
  always marked unverified, including an exact "USDT" match.
- **Privacy startup fix.** The transport is rebuilt after preferences load,
  so a configured Tor/proxy route applies to the first request instead of
  silently going direct. Cold mode now blocks price lookups and explorer
  history, and USD prices default to off.
- **Node credentials.** Proxy passwords, bearer tokens and custom headers are
  kept in the platform secure store; the plain node book and the export no
  longer contain them.
- **RPC limits.** Responses are capped at 2 MiB, methods are allowlisted,
  URLs with credentials and cloud-metadata/link-local targets are refused.
- **Erase completeness.** "Erase all data" removes every registered vault,
  the activity log and crash-orphaned atomic temp files.
- **Branding.** The user-visible name is exactly **X Wallet** in the desktop
  entry, window title, About title and Debian description. The version is
  shown separately.

## Breaking changes

- Backups exported by 1.5.3 are portable (`BNBBKP01`). Older `BNBVL004`
  backups still import on the same device, but they still require that
  device's secret.
- Pending transactions written by older versions are adopted by the active
  vault on first run.

## Verification

The release evidence, hashes, SBOM and signatures are published with the
release. The repository's `verify` workflow must be green for the tagged
commit. This release does not claim an independent audit, a physical
two-device cold-signing test, or large-value certification.
