# X Wallet 2.0.0-rc.2

Source version: `2.0.0-rc.2+20`
Released: 2026-11-13
License: AGPL-3.0-or-later
Platforms: Linux amd64; Android builds not produced for this RC

This is a **pre-release**. The full risk register is `RISKS.md`; do not use this
build for large holdings.

## Included

- BNB Smart Chain and Ethereum (from 1.6.0).
- Bitcoin, Litecoin and Dogecoin transparent UTXO support:
  BIP44/49/84/86 derivation, P2PKH/P2SH-P2WPKH/P2WPKH/P2TR addresses,
  WIF/raw import, UTXO discovery, fee/coin selection, change, signing,
  serialization, TxID, broadcast and confirmation status.
- Real regtest transactions for BTC/LTC/DOGE with independent signature checks.
- Per-chain RPC and explorer keys, selectable price provider, kill switch.
- Official chain marks, standard wallet hero and explicit network badges.
- Single risk register: `RISKS.md`.

## Not included

- Public BTC/LTC/DOGE testnet proof.
- PSBT, descriptors, xprv/xpub, watch-only, gap-limit recovery, RBF.
- Litecoin MWEB (explicitly unsupported; UI warns).
- Hardware wallet, multisig, two-device offline signing.
- Physical Android/phone test; Android build for this RC.
- Independent rebuild or independent professional audit.
