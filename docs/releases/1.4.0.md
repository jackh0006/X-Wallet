- Historical compromised signer: denylisted.
- New release signer: generated outside the repository, 4096-bit RSA.
- The public certificate SHA-256 is the approved signer fingerprint.
- The private keystore is not in Git.
- The release owner must back up the keystore; losing it prevents in-place
  updates under the same Android identity.

## What remains platform-specific

Android uses the Android Keystore, the Android app sandbox, and the Android
file picker. Linux uses the Linux keyring/drawer, POSIX file checks, and desktop
file dialogs. The wallet logic, vault, tokens, spending controls, and cold
protocol are shared.
