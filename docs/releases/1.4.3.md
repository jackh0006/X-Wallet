# X Wallet 1.4.3+12 — USD values, send balance, and saved activity

Source version: `1.4.3+12`. This release shows public USD prices under assets,
shows the available balance while sending, keeps sent and pending transfers in
the app, and keeps the app English-only.

## What changed

- Android wallet dashboard shows the BNB balance with its public USD value,
  and every asset card shows the asset value in USD.
- Home balance rows show a USD line under each token.
- Send shows the available balance and its USD value for the selected asset
  before the transfer is reviewed.
- Recent activity on Android lists pending transfers and saved receipts. The
  records stay local and encrypted at rest.
- Prices come from the public CoinGecko `simple/price` endpoint. The request
  contains only fixed coin IDs; it never contains an address, balance, vault,
  seed, or user identifier.
- The privacy route test, the proxy test, and the external Tor test display
  the public IP seen by the outside service on the exact active route.
- The app is English-only.
- Linux desktop layout is unchanged.
