# X Wallet 1.5.5

Source version: `1.5.5+17`
Released: 2026-11-12
License: AGPL-3.0-or-later
Platforms: Linux amd64, Android arm64/universal

This release completes the 1.5.4 self-audit follow-up with additional
transaction, cold-pairing, network, storage and release-gate hardening. It is
still **not an independent audit** and is not approved for large amounts.

## Security changes

- Transaction signing now binds the reviewed **nonce** and **sender** to the
  exact transaction object before signing, not just chain/recipient/amount/fee.
- Cold pairing fingerprints now cover the **chain and every paired address**
  (64-bit hex + shapes), not four bytes of the first address.
- Legacy pre-1.2 application-data directories are now included in
  “Erase all data”, including their vault and plaintext device secret.
- Android file import is bounded to 8 MiB (no unbounded `ByteArrayOutputStream`).
- Custom RPC headers now reject cookies, referer/origin, authorization,
  API keys, host/framing headers, CR/LF and oversized values.
- The release gate has a strict source mode for CI and a post-release
  `release-verify` workflow that downloads the published assets, verifies
  `SHA256SUMS`/GPG, checks the APK signer and runs the strict artifact gate.
- CI release-build tags are gated by the source release gate.
