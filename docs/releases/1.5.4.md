## Audit fixes in this release

- Fixed the erase-all process-lock deadlock and added a regression test.
- Bound cold ERC-20 approve/increaseAllowance/transferFrom to the actual
  token contract; the cold review shows the contract.
- Enforced spending policy and chain ID on cold sign/broadcast.
- Blocked removal of unknown-broadcast rows; no blind retry.
- Validated mixed-case EIP-55 input; rejected typos.
- Clamped PIN backoff and enforced it inside PIN verification.
- Mobile keyring fails closed when a vault exists but the secret is missing.
- Suppressed public RPC fallbacks when a per-node Tor/custom transport is
  configured; Tor failure now fails closed instead of going direct.
- Gated fee quotes and IP/route probes in cold mode.
- Erased node credentials with “Erase all data”.
- Removed debug-signed APK uploads from CI; ARM-only universal CI build.
- Added `util-linux` for the offline launcher and a distinct cold desktop entry.
- Added official BIP-39 vector, EIP-55 typo, backoff and contract-binding tests.

## Android upgrade boundary

1.5.4 uses the 1.5.3 certificate
`2a96a384eb0db55bb4fb0fb2107df386ecc595b38bc46225ef9b18309d93ba9a`.
It cannot upgrade a 1.5.1 install (`db12869c…9748d3`) in place. Export a
portable backup, uninstall 1.5.1, then install 1.5.4.
