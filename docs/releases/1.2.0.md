## Compatibility decisions

- Dart package `bnb_wallet_gui`, Linux binary `bnb_wallet_gui`, vault magic and
  filenames, backups, device-secret identifiers, data paths, and `BNB_*`
  environment variables remain unchanged.
- Debian package `x-wallet` continues to replace `bnb-wallet` and keep the
  `/usr/bin/bnb-wallet` compatibility alias.
- Linux application ID and desktop WM class are now
  `com.jackh0006.xwallet`.
