# X Wallet 1.6.0

Source version: `1.6.0+18`
Released: 2026-11-13
License: AGPL-3.0-or-later
Platforms: Linux amd64, Android arm64/universal

This release adds first-class **Ethereum** support, per-chain explorer keys,
user-selectable USD price providers and a stricter chain-aware UI on top of the
1.5.5 security hardening. It is **not an independent audit** and is not
approved for large amounts.

## New functionality

- **Ethereum mainnet (1) and Sepolia (11155111)** share the EVM engine with
  BNB Smart Chain (56/97).
- **Ethereum default tokens:** USDT, USDC and XAUT (Tether Gold), with the
  canonical contracts and 6 decimals.
- **Per-chain explorer keys:** BscScan for BNB, Etherscan for Ethereum; a key
  is never reused across chains.
- **Ethereum history** uses Etherscan v2 with the correct chain ID.
- **Price provider selection:** automatic, CoinMarketCap, CoinGecko or Binance.
  Optional API keys are stored in the platform secure store. A pinned provider
  never silently falls back.
- **Chain-aware UI:** native symbol, network name and explorer are read from
  the chain registry on Home, Send, Wallet, Receipt, Activity and Settings.
- **Cold signer** accepts every registered chain and rejects unknown chain IDs,
  with EIP-1559 type-2 transactions.
