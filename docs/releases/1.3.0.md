## What changed

- Multiple wallets in one encrypted vault: add, switch, rename, remove.
- One vault password for all accounts; a second password cannot create a
  second container.
- Legacy Linux application-directory migration, fixing wrong-password reports
  after the 1.2.0 application-ID rename.
- Any non-empty vault password; no trimming; confirmation field; live
  Very weak → Very strong score.
- USDT and USDC merged into every BSC wallet beside BNB.
- Verified public RPC defaults: BNB Chain, PublicNode, 1RPC, Blast, 48.club.
- Private-key-only wallets can export a cold pairing and sign offline.
- BscScan history requests use the chain-aware V2 endpoint.
