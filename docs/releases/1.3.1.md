## Root cause of the vault failure

The vault decrypted correctly with the user's password. Account parsing then
called `WalletCore.privateKeyFromHex` on a stored key with an insignificant
leading `00` byte (66 hex characters). That threw "Private key must be 64
hexadecimal characters", and the UI displayed every vault exception as a wrong
password.

Fix:

- `WalletCore.normalizePrivateKeyHex` accepts leading-zero key forms.
- `AppState` uses it on vault read and stores normalized keys on save.
- The UI distinguishes a decryption failure from an invalid account record.
- Regression tests cover the exact 66-character key and a real vault unlock.
