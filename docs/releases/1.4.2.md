## What changed

- Android opens on a soft wallet dashboard with a BNB hero card, Send/Receive,
  one Save to vault action, an asset list, and saved wallets.
- Standard English-only UI; the language selector is removed.
- Privacy route test now shows the public IP that an outside service sees on
  the exact active route (the exit IP under Tor/proxy).
- Vault no longer auto-locks on Android `inactive` transitions or background
  unless the optional app lock is enabled. Manual Lock still works.
- Transfer confirmation now asks the user to type a short word displayed by
  the app, followed by hold-to-confirm.
- Linux desktop layout is unchanged.
